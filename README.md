# 霍格華茲藏書室

繁體中文／英文雙語七部曲導覽，採米色紙張、酒紅色與鋼筆淡彩的書籍風格。使用原生 HTML、外部 CSS 與 JavaScript，無需建置或後端。

## 下載與作業繳交

下載 ZIP 後請先完整解壓縮，再用瀏覽器開啟 dist/index.html。網站圖片與程式都在 dist，不需要登入或安裝套件。沒有網路時使用系統字型，官方參考連結需連線。

這份儲存庫刻意不包含私人對話紀錄。若作業要求 AI 對話，請將本機的匯出紀錄另外加入繳交 ZIP；不要直接上傳對話到 GitHub。排除範圍見 [GITHUB-EXPORT.md](GITHUB-EXPORT.md)。

## 2026-10-18 視覺更新

兩種測驗共用相同細框、紙色底與內距，測驗解析採較短行長及一致段落間距；導覽、小說與測驗等區保留手機文字與操作改善。人物與神奇動物依使用者要求恢復原樣。題庫與保存資料不變。實測與限制見 VERIFICATION.md。

## AI 維護入口

之後的 AI 請先讀 [AGENTS.md](AGENTS.md)，再讀 [ARCHITECTURE.md](ARCHITECTURE.md) 的完整架構與資料契約，以及 [MAINTENANCE.md](MAINTENANCE.md) 的更新、測試、發布與故障處理流程。這三份文件隨來源碼保存，不必依賴本次對話才能接手。

## 開啟網站

直接開啟 `dist/index.html`，或執行 `node tools/preview.cjs`，瀏覽 `http://127.0.0.1:8765`。本機檔案模式的剪貼簿限制會提供手動複製方式。

此 GitHub 副本供下載原始碼與本機閱讀，不含原私人網站的網址、託管識別資料或存取設定。

## 內容與互動

- 頂端「中文 / English」與檔案視窗內語言切換，記住選擇；切換不重載頁面，保留當前作答、收藏、檔案與聯絡草稿。
- 七部小說介紹、鍵盤切換、閱讀進度、劇透保護。
- 十二位人物的官方電影照片、背景、專長、關聯人物與小說、搜尋與收藏。
- 十二種神奇動物的鋼筆淡彩插畫、分類、搜尋、習性與收藏。
- 分院儀式上方提供四大學院介紹、創辦人、代表動物及小說代表色。
- 十六題分院遊戲，提供四院傾向、同分選擇與複製結果。
- 三十題學生知識測驗，基礎、進階與挑戰各十題，涵蓋七部小說。
- 學生測驗可暫停、續答、返回修改、交卷前檢查、查看逐題解析及錯題、返回相關小說。
- 成績包含 O.W.L.s 等第、答對題數、各難度表現、本機最佳紀錄與複製成績。
- 自我介紹、HTML／CSS／JavaScript 技能展示、貓頭鷹郵局的訊息撰寫與複製。
- 響應式導覽、語意標籤、原生表單、鍵盤焦點及對話框 Escape 關閉。

所有記錄只保存在目前瀏覽器，沒有伺服器帳號成績資料庫。瀏覽器停用儲存時仍能完成當次作答。兩種測驗各自保存，互不覆寫。

## 人物照片

依使用者允許改採網路照片的指示，十二位人物已換成 HarryPotter.com 官方人物百科中的電影照片。每張使用 1200 × 832 WebP，在人物詳情顯示原色照片及可點擊的來源；無拉伸或正方形裁切。照片保存於本站，避免直接外連圖片造成載入不穩。

來源與素材網址見 PHOTO-SOURCES.md。這些是既有電影照片，並非 AI 重繪或免版權素材；權利歸原權利人。GitHub 上傳時使用私人儲存庫。先前 SVG 保留在來源中供歷史參考，目前人物檔案均使用 WebP。

## 修改內容

- `dist/data.js`：站長名稱／信箱、七部小說、人物與生物。信箱目前留空，不會實際寄信。
- `dist/index.html`：語意版面、自我介紹、技能展示。

- `dist/app.js`：閱讀、圖鑑、搜尋、收藏及分院流程。
- `dist/exam.js`：學生測驗流程、作答保存與成績。

- `SOURCES.md`：設定來源與三十題的小說章節索引。
- `TERMINOLOGY.md`：台灣譯名、核對依據與維護規範。

## 計分

分院遊戲每題所選學院得 1 分，十六題共 16 分，不含次要加分。每題四院各有一個選項，四院在每個選項位置各出現四次。同分由使用者選擇，不以學院排序決定。第 3 版改寫情境與選項，因此舊八題及第 2 版十六題的分院答案需重新作答；畫面會說明更新，閱讀、收藏、語言與學生測驗紀錄不受影響。

學生測驗每題 1 分，共 30 分，不倒扣：

| 等第 | 英文名稱 | 答對題數 | 狀態 |
| --- | --- | --- | --- |
| O | Outstanding | 27–30 | 及格 |
| E | Exceeds Expectations | 23–26 | 及格 |
| A | Acceptable | 18–22 | 及格 |
| P | Poor | 12–17 | 未及格 |
| D | Dreadful | 6–11 | 未及格 |
| T | Troll | 0–5 | 未及格 |

等第名稱來自小說；中文等第依台灣皇冠版；數字門檻、鼓勵評語與測驗題目為本站設計，並非官方考試。開始前提醒涵蓋結局，小說區的劇透開關不控制測驗題目。
